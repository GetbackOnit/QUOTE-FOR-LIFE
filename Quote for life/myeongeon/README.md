# 오늘의 한 줄

기분·지금의 상태·채용 일정에 맞춰 고전의 한 줄을 건네는 개인용 명언 앱 (설치형 웹앱, PWA).
Mac 없이 아이폰·안드로이드·PC 어디서나 씁니다. 서버가 없고, 모든 데이터는 내 기기에만 저장됩니다.

## 1. 지금 바로 써 보기 (내 PC에서)

```bash
cd myeongeon
python3 -m http.server 8000      # Windows는 python -m http.server 8000
# 브라우저에서 http://localhost:8000
```
`index.html`을 더블클릭해서 열어도 화면은 뜨지만, 오프라인 설치(서비스 워커)는 `http://` 또는 `https://` 주소에서만 켜져요.

## 2. 폰에서 쓰려면: 무료 호스팅에 올리기 (HTTPS 필요)

가장 쉬운 방법 세 가지 (모두 무료):
- **Netlify Drop**: `app.netlify.com/drop` 에 폴더째 끌어다 놓기 → 주소가 바로 생겨요.
- **GitHub Pages**: 저장소를 만들어 이 폴더 파일을 올리고, Settings → Pages 에서 켜기. (포트폴리오로 쓰기에도 좋아요.)
- **Cloudflare Pages**: 저장소 연결 또는 폴더 업로드.

## 3. 홈 화면에 설치

- **iPhone**: Safari로 주소 열기 → 공유 버튼 → "홈 화면에 추가". (크롬이 아니라 Safari 권장)
- **Android**: Chrome 으로 열기 → 메뉴 → "앱 설치" 또는 "홈 화면에 추가".

## 4. 알림 받는 법 (중요)

웹앱은 **서버 없이 정해진 시간에 알림을 보낼 수 없어요.** 그래서 이 앱은 알림이 울리는 **캘린더 파일(.ics)** 을 만들어 줘요.

1. 설정 → 알림 시간 켜기 (아침 / 낮 / 저녁) → 기간 선택 → "알림용 캘린더 파일 만들기"
2. 받은 파일을 열어 캘린더에 추가 (가능하면 별도 캘린더로)
3. 정해진 시간에 기본 캘린더 알림으로 그날의 한 줄이 떠요.

한계: 파일을 만든 시점의 상태·일정만 반영되고, 그날의 기분 체크는 반영되지 않아요. 일정이 바뀌면 파일을 다시 만들어 주세요.
(서버 푸시 알림은 2단계로 붙일 수 있어요. Cloudflare Workers 같은 무료 서버리스를 쓰는 방식입니다.)

## 5. 이 앱이 명언을 고르는 방식

점수를 매겨 확률적으로 고릅니다. 같은 날·같은 시간대는 항상 같은 말이 나오고, "다른 말" 버튼으로 바꿀 수 있어요.

| 입력 | 반영 |
|---|---|
| 오늘 기분 (1~5) | 힘든 날은 위로·진정 위주, 좋은 날은 격려·도전 위주 |
| 상태 (지원 중 / 면접 준비 / 결과 대기 / 탈락 직후 / 쉬는 중) | 상태 태그가 맞는 말에 가중 |
| 일정 | 면접 3일 전, 발표 3일 전, 마감·시험 2일 전부터 자동 반영. 하루 전이면 더 강하게 |
| 시간대 | 아침은 꾸준·격려, 저녁은 진정·위로 쪽으로 약간 |
| 최근 본 말 | 최근 30개는 거의 안 나옴 |

## 6. 내 명언 추가 · 데이터 · 백업

- 설정 → "내 명언 추가"에서 직접 넣을 수 있어요. 어울리는 분위기·상황 태그를 고르면 같은 로직으로 섞여 나와요.
- 기본 명언은 `quotes.js`(33개)와 `quotes-extra.js`(74개)에서 고칠 수 있어요. 형식은 파일 맨 위 주석 참고.
- 데이터는 **브라우저 저장소**에만 있어서 사이트 데이터를 지우면 사라져요. 설정 → "백업 파일 저장"으로 가끔 내려받아 두세요.
- 파일을 고친 뒤 배포할 때는 `sw.js` 의 `VERSION` 숫자를 올려야 폰에 새 버전이 반영돼요.

## 7. 출처와 저작권

- 원문은 저작권 보호기간이 지난 고전(논어·맹자·순자·중용·대학·주역·도덕경·장자·법구경·선어록, 스토아와 라틴 시인, 19세기 이전 서양 문인 등)과 속담이고, 한국어는 직접 옮긴 번역입니다. 시중 번역본 문장은 쓰지 않았어요.
- 출처 확인 수준은 앱 카드 아래에 표시됩니다. (2026-10-14 개발 중 온라인 자료와 대조)
  - **✓ 구절 번호 대조함 (20개)**: 법구경 1·2·5·25·35·43·50·82·83·103·112·160·204·239·276번, 마르쿠스 아우렐리우스 4.3·5.1·5.16·10.16, 릴케 제4신
  - **✓ 원문·편명 대조함 (5개)**: 논어 술이 3곳, 순자 권학 2곳 (글자와 편명만 확인, 장·절 번호는 미확인)
  - **고전 원전의 장·절 표기 (대조 안 함)**: 위 외의 한문 고전·라틴 시인·서양 문인 등. 접속이 막히거나 자료를 찾지 못해 대조하지 못했어요. 인용할 땐 원전 확인을 권해요.
  - **전승되는 인용 (4개)**: 이순신 장계, 지눌 『수심결』, 이양연 「야설」, 니체 인용. 원문 표기나 작자가 판본·해석에 따라 달라질 수 있어요.
  - **속담**
- 한국어 해설(note)은 출처가 아니라 해석이에요. 취향에 안 맞으면 `quotes.js` 에서 지우거나 고치세요.
- 다른 책의 문장이나 노래 가사를 그대로 넣는 것은 피하고, 내 말로 바꿔 적는 것을 권해요.

## 8. 스토어에 올릴 때 (선택)

- 이 코드는 웹 기술이라, 스토어용 앱으로 감싸려면(Capacitor 등) 추가 작업이 필요해요.
- 애플은 "웹사이트와 다를 바 없는 앱"을 최소 기능 기준(가이드라인 4.2)으로 거절하는 사례가 많아요. 올릴 계획이 생기면 위젯·로컬 알림 같은 네이티브 기능을 붙인 뒤 시도하는 걸 권해요.
- 구글 플레이는 개인 계정의 경우 12명 테스터가 14일 연속 참여하는 테스트를 거쳐야 해요.

## 파일 구성

```
index.html            화면 틀
app.css               스타일 (밝은/어두운 테마)
app.js                앱 로직 (기분·일정 반영 선택, 저장, 캘린더 파일, 이미지 카드, 백업)
quotes.js             기본 명언 33개 (태그·출처 포함)
quotes-extra.js       추가 명언 74개 (같은 형식)
sw.js                 오프라인 캐시
manifest.webmanifest  설치 정보
icon-*.png            아이콘
```
